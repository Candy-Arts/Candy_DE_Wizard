# Candy DE Wizard
**Candy DE Wizard provides several features related to Candy Dialogue Engine:**<br>
• Download, install and update Candy Dialogue Engine into Godot projects.<br>
• Various tools for managing Candy Dialogue Engine.<br>
• Download Candy Database + the Candy Dialogue Engine documentation.<br>
• Display important news from Candy Arts.<br>
• Update the Wizard itself when new versions are released.<br>

## Compatibiliy
Candy DE Wizard is compatible with Godot 4.7+ (4.7 and above).

## Installation
1. In your Godot project's root folder, create a folder named 'addons' if you don't have one.
2. Place the Candy\_DE\_Wizard folder in the 'addons' folder.
3. In Godot editor, enable the Candy DE Wizard plugin: Project > Project Settings > Plugins
4. Restart Godot.

## Usage
The Wizard adds a tab in the Godot Editor bottom dock, where all tools and features can be found.

## Disclaimer
Several tools connect to GitHub to check for updates and to download files.

For security, the Wizard checks that all files containing code are signed by Candy Arts.
